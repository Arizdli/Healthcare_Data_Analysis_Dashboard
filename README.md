# Healthcare Patient Analytics Dashboard
## Project Objective
An interactive Power BI dashboard that analyzes patient demographics, diagnoses, treatment plans and key health indicators (heart rate, blood pressure, cholesterol, BMI) for 500 patients between 01-01-2024 and 14-05-2025.
